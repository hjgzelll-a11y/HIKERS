## 📖 About the Project

HIKERS is a web-based hiking booking platform that allows users to explore hiking destinations, view schedules, and reserve hiking trips online. It provides a simple system for managing bookings for both users and administrators.

---

## 🚀 Key Features

### 👤 User Features
-🔐 User Registration and Login
-🏔️ Explore Hiking Destinations
-📅 View Hiking Schedules
-📝 Make Hiking Reservations
-❤️ Add Mountains to Favorites
-📖 View Booking History
-🗺️ Interactive Maps and Location Viewing
-🏆 User Achievements and Hiking Progress
-👤 User Profile Management
-⭐ Submit Reviews and Ratings

## 🏗️ System Architecture

The HIKERS platform follows a **Client-Server Architecture**.

### 💻 Frontend
Built using **React.js**, the frontend allows users to:
- Browse hiking destinations  
- View schedules  
- Make reservations  
- Manage bookings  

### ⚙️ Backend
Developed using **Node.js** and **Express.js**, the backend handles:
- API requests  
- Booking management  
- User authentication  
- Database operations  

### 🗄️ Database
The system stores:
- User accounts  
- Hiking destinations  
- Booking records  
- Reservation details

## 🖥️ Deployment

The system was originally set up on an **Ubuntu Server OS** using a configured web server and FTP/SCP for file transfer and deployment during development.

For easier access and presentation purposes, the frontend of the system is also deployed on **Vercel**, allowing users to access the application through a public link.

- 🌐 Frontend (Vercel): https://hikers-mu.vercel.app  
- ⚙️ Server (Ubuntu VM): Used for backend deployment and development testing
